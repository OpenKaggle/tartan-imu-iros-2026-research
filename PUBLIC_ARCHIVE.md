# Public archive scope

This repository is a source, notebook, protocol, and evidence archive for the [TartanIMU Challenge](https://www.kaggle.com/competitions/tartan-imu-challenge-iros2026). Its competition data has an explicit CC BY-NC-SA and competition-use boundary, so the data and official weights are deliberately not republished here.

Tracked files are the original research methods and reproducibility records. Environments, raw inputs, model weights, generated submissions, and caches are excluded.

Portfolio index: [kaggle-research-portfolio](https://github.com/openkaggle/kaggle-research-portfolio). Related archives: [Nemotron reasoning](https://github.com/openkaggle/nemotron-reasoning-research), [NeuroGolf ONNX](https://github.com/openkaggle/neurogolf-2026-onnx-research), and [Maze Crawler](https://github.com/openkaggle/maze-crawler-research).
